# 🍽️ Delicious Bites Restaurant Website

A modern, responsive restaurant website designed for a professional restaurant business.

## 🌐 Project Overview

Delicious Bites is a responsive restaurant website that allows customers to:

- Explore the restaurant's menu
- View food images through the gallery
- Learn about the restaurant
- Select meals and quantities
- Automatically calculate their order total
- Submit an order through the website
- Send their order directly through WhatsApp
- Contact the restaurant
- Use the website comfortably on desktop, tablet, and mobile devices

## ✨ Features

### 🏠 Homepage
- Professional hero section
- Restaurant introduction
- Call-to-action buttons
- Restaurant statistics

### 🍴 Menu
- Food cards with images
- Meal prices
- Ratings
- Order buttons
- Quick navigation to the order section

### 🖼️ Gallery
- Restaurant and food images
- Interactive image lightbox
- Full-screen image viewing
- ESC key support for closing the lightbox

### 🛒 Online Ordering
- Customer name
- Phone number
- Meal selection
- Quantity controls
- Automatic price calculation
- Delivery address
- Form validation
- Order confirmation
- WhatsApp ordering

### 📱 Responsive Design
The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile phones

### ⚡ Performance
- Lazy-loaded images
- Loading screen
- Scroll progress indicator
- Smooth scrolling
- Efficient JavaScript interactions

### ♿ Accessibility
- Meaningful image `alt` text
- Semantic heading structure
- Accessible navigation controls
